> **목적**: X 알고리즘의 '외부 링크 노출 패널티'를 피하고, 팬덤의 **인용 리트윗(QRT)**과 **댓글 승부욕**을 자극하는 실전 홍보 문구 모음입니다.  
> **최종 업데이트**: 2026-10-20  
> **공식 도메인**: `https://kpulsequiz.com`

## ⚠️ [필수 원칙] X 알고리즘 노출을 3배 높이는 '2단 트윗(본문+답글)' 규칙

X(트위터)는 **본문에 외부 URL(`https://...`)이나 해시태그가 덕지덕지 붙은 트윗의 노출(Reach)을 50~80% 이상 삭감**합니다.  
따라서 모든 포스팅은 반드시 아래 **[본문 트윗] + [내 트윗에 바로 다는 첫 번째 답글]** 세트로 올립니다.

1. **[1단: 본문 트윗]**
   - **외부 링크 절대 금지** (URL 넣지 말 것)
   - **이미지 1장 필수 첨부** (결과 카드 캡처, 킬러 문제 1개 캡처, 또는 `/record`로 찍은 15초 영상)
   - 해시태그는 아예 안 쓰거나 **딱 1~2개만** 본문 끝에 자연스럽게 포함
2. **[2단: 첫 번째 답글 (Reply)]**
   - 본문 트윗을 올린 직후, 바로 밑에 답글로 **퀴즈 링크(`https://kpulsequiz.com/quiz/...`)**를 답니다.

## 3. ⚔️ '1:1 친구 도전장 (`?c=` 링크)' 직접 투척 문구

> **사용법**: 내가 직접 사이트에서 5문제를 빠르게 풀어 **4,300~4,800점대**를 만든 뒤, 결과창에서 닉네임(예: `Hobi🐯`)을 입력하고 `[⚔️ 도전장 메시지 복사]`로 나온 **`?c=...` 실제 대결 링크**를 사용하는 템플릿입니다.  
> **효과**: 클릭한 사람이 일반 모드가 아니라 **"실시간으로 내 점수와 1:1로 맞붙는 대결 HUD 화면"**으로 진입하여 전환율과 재공유율이 가장 높습니다.
